# Zeluvia — Aubaines d'épicerie de la semaine

Application web installable (PWA), bilingue FR/EN, qui rassemble les meilleurs prix de la semaine chez Maxi, Super C, Metro, IGA, Provigo et Walmart (Québec, Canada) et aide à faire sa liste d'épicerie par magasin.

- Prix mis à jour chaque jeudi à partir des circulaires officielles.
- Aucun prix n'est inventé : chaque prix affiché provient d'une circulaire vérifiée.
- Fait par Kimly Chao, Québec, Canada.
